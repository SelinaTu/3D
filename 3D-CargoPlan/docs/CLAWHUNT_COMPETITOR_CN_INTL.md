# 国内外智能装柜竞品对比（2026-10-30）

依据：你提供的国内调研 + 官网核对（装箱大师 / 悠闲装箱 / 智火 U3）+ EasyCargo 官网与文档 + 此前 X 侧线索。  
结论先行：**国内外都已从「能不能算出布局」进入「约束、集成、现场可执行」；多站装卸顺序也不是空白。差异机会不在「又一个 3D 装箱器」，而在「可解释的逐站倒货 / 通道冲突 + Agent 约束闭环 + 可审计任务输出」。**

## 1. 市场阶段（共识）

| 阶段 | 国内外现状 |
| --- | --- |
| 算得出来 | 成熟：Excel 导入、多柜/多车、3D、步骤图、手动改 |
| 复杂约束 | 国内产品表非常细（承重级、成套、打托再装柜、膨胀间隙、群组…）；海外 EasyCargo 偏车辆轴荷、优先级组、虚拟墙 |
| 企业集成 | 国内强调 ERP/WMS/移动端查验；海外 EasyCargo 有 SAP / API / make.com |
| 现场可执行 | 双方都有步骤图 / 分享链接；**很少公开「因遮挡产生的倒货次数与逐步稳定状态」** |

你的调研判断成立：国内不是缺算法，而是拼约束深度、集成与现场落地。

## 2. 国内三家核对摘要

### 装箱大师（LoadMaster）· [功能表](https://www.zhuangxiang.com/product/)
- **定位**：成熟专业装柜；桌面 + 云端分层（标准/专业）。
- **强项**：约束菜单极全——空间顺序、承重级别、成套、塞货、群组同柜、打托再装柜多模式、固定部分方案重算、重心、手动跨柜拖货、移动端定位/海关查验叙事、ERP/WMS。
- **多站相关**：官方写明「不同目的须指定装载顺序 / 空间顺序」；英文文档有 Loading Sequence（相对值，越大越先装）。
- **对你们**：正面竞品天花板。Hackathon 勿比「功能条数」，要比「异形约束证据 + 卸货遮挡解释」。

### 悠闲装箱（OptimalPacking）· [会员权益](https://www.optimalpacking.cn/memberequity/)
- **定位**：在线 SaaS + 铁路/跨境/中小制造；还带「找线路」询价揽货（偏供应链交易）。
- **强项**：浏览器、3D 动画、装箱指导图（分段步骤）、破损货、膨胀、叉车/门尺寸、重心、手动改；VIP 含分组、**按组顺序装载（多仓装货/多目的卸货）**、部分重算、先打托后装箱。
- **边界**：公开写明算法面向近似立方体，**圆柱/锥/异形暂不支持**——与伊拉克门窗/玻璃架场景形成对比切口。
- **商业**：免费额度 + VIP + 企业定制（完整报价未公开）。

### 智火装箱 U3 · [U3](https://www.zhihuo.com/u3/)
- **定位**：老牌计算工具；U3 专注打托货/平放单元混装。
- **强项**：自动算 + **二维手动编辑**（现场沟通友好）、红绿灯加减托、已装一半柜只排剩余空间、重心左右/前后、Excel 主数据。
- **边界**：偏托盘单元货，不是异形门窗工程柜；多站叙事弱于「装载顺序字段」，更强在「人机共改方案」。

## 3. 海外代表：EasyCargo（及同类）

来源：[官网](https://www.easycargo3d.com/en/)、[Priority Groups](https://www.easycargo3d.com/en/journal/do-you-need-to-load-or-unload-the-cargo-gradually-with-priority-groups-its-a-piece-of-cake/)

| 维度 | EasyCargo |
| --- | --- |
| 形态 | 浏览器 SaaS，卡车/半挂/集装箱/托盘谱系完整 |
| 多站 | **Priority Groups** 一等公民：LIFO、组间隔离/禁止叠放/虚拟墙/忽略分组比利用率 |
| 物理 | 轴荷与重量分布是营销核心（过磅罚款叙事） |
| 交付 | 步骤报告、PDF、公开 3D 链接、Excel、SAP/API |
| 弱项（相对你们场景） | 公开材料偏规则箱/托盘；少见「中文复杂异形约束证据链」；少见「逐步卸货时阻挡物清单与倒货计数」 |

同类海外：CargoLoader3D（分组开关）、LoadMaster 英文站（与装箱大师同源产品线）、InstaDeep DeepPack（AI+routing）、Truck Packer / CargoOptix 等轻量新人。

## 4. 国内外差异一张表

| 维度 | 国内主流 | 海外（以 EasyCargo 为主） | 对 CargoPlan 的启示 |
| --- | --- | --- | --- |
| 核心单位 | 集装箱 / 外贸柜 + 打托再装柜 | 卡车轴荷 + 集装箱 | Demo 可柜可车；卡车讲轴荷，工程柜讲异形 |
| 约束深度菜单 | 极深（成套、塞货、群组、膨胀…） | 相对精简但产品化清晰 | 别堆菜单；挑 3–5 条可演示硬约束 |
| 多站 | 「空间顺序 / 按组顺序」有，多为装载优先级 | Priority Groups 产品化更强 | **不能说独家多站**；要比「卸货遮挡可解释」 |
| 异形/工程货 | 多数默认立方体纸箱托盘；悠闲明示不支持异形 | 同样偏规则货 | **伊拉克门窗玻璃架是差异资产** |

| 商业 | 桌面授权 + 云箱数 VIP + 项目定制 | 订阅清晰、学校计划、企业折扣 | 中小嫌贵（X 有机信号）；可讲轻量可审计 |
| AI/Agent | 「AI/强化学习」品牌多，Agent 工作流少 | 少见 NL→约束→再校验闭环 | **Agent 赛道叙事窗口仍在** |
| 机器人 | 几乎不谈柜内作业序列 | 几乎不谈 | 任务草案是蓝海，须划清边界 |

## 6. 给黑客松的定位话术

**一句话**  
国内外装柜软件已解决「怎么摆满柜子」；CargoPlan 解决「多站卸货时谁挡了谁、要倒几次、约束从哪来、给人和机器人同一份可审计作业」。

**对国内**：不和装箱大师比功能表长度；比异形工程约束 + 卸货过程仿真。  
**对 EasyCargo**：承认 Priority Groups；补「分组装完后仍可能的遮挡逐步分析」与中文复杂约束证据。  
**对悠闲**：他们不做异形——你们用门窗玻璃架样例打差异。

## 7. 建议路演不要说 / 要说

- 不要说：国内没有智能装箱；我们独家多站；我们独家 3D。  
- 要说：市场已有装载顺序与分组；现场仍缺**可重放的倒货成本**与**改单后约束复核**；我们用 Agent 把自然语言/Excel 约束落到确定性求解，并用 3D 逐步证明。
