# CargoPlan 1.5 · 货舱调整与车型装卸

2026-10-31。安装入口：`/Applications/CargoPlan 1.5.app`。并行保留旧版，避免影响已打开的编辑会话。网页与原生应用共用装配和多站点引擎。

## 用户操作

### 装配

左侧常驻「货舱尺寸」，可输入内长、内宽、内高，点击「应用货舱尺寸」或按回车。此处作用于当前方案的全部同规格货舱。选中货物的原有尺寸、承重、方向编辑仍保留。

勾选「在 3D 中拖拽调整货舱」，拖蓝、绿、橙手柄调整长、宽、高，按 10 mm 步长预览，松手应用；Esc 取消当前拖动。该模式下空白仍可旋转视角，退出后恢复货物拖动。

只把越界或超载货物转入待装池；其余保留原位。所有货物守恒，不因缩小货舱被删除。支持撤销上次货舱调整；其他货物编辑或重新计算后清除此快照，避免撤销误覆盖后续工作。

改尺寸不自动计算，点击「重新计算」完成留缝、方向、承托和数量校验。启动前和运行中均可取消，迟到的旧计算回调不会覆盖当前工作；成功摘要直接显示在界面内。

仅改长/宽，且原项目内高和留缝不变时，保留原项目装载规则与来源高度例外；改变内高或留缝切换为自定义约束。没有变化的应用操作不会重置规则。求解修复先独立检查旧方案，再按新规格修复，避免把旧基线直接丢弃。

### 多站点

「编排需求」顶部先选车型模板、调整实车净空/载货与可用装卸面，再输入站点及装卸需求；点击「计算装卸方案」。更换车型保留起点货物和各站需求，原执行结果失效，主动计算后采用新规格。

| 模板 | 默认作业 | 对求解的影响 |
|---|---|---|
| 4.2 / 6.8 / 9.6 米厢车 | 后门，工人通道 | 早卸货水平靠后门；校验走道和取货距离 |
| 13 米侧帘车 | 左右侧、后门，设备抽取 | 逐件选择畅通的可用面，减少因车尾阻挡造成的倒货 |
| 6.8 米栏板车 | 栏板开启后左右侧、后门 | 按开放面模拟叉装，不把关闭栏板当作可穿越 |
| 13 米平板吊装车 | 顶部，设备吊装 | 校验垂直抽取柱与承托，上方货物先处理 |
| 20 尺普通箱 / 40 尺高柜 | 端门，工人通道 | 与原装箱约束及端门路径共用逻辑 |
| 自定义 | 可编辑面及人员/设备方式 | 明确输入假设，不能静默绕过约束 |

尺寸、载重均为可编辑的演示默认值，不是统一厂型参数或法规限值。集装箱沿用系统通用示例；实车净空、箱号铭牌和额定载货应由用户填写。

侧帘的侧向/后端作业参考 [Schmitz Cargobull 侧帘资料](https://www.cargobull.com/kz/-/media/project/scb-sites/scb-global-site/media-center-en/brochure-scs-curtainsider-semi-trailer.pdf)。集装箱尺寸差异参考 [ONE 设备规格](https://www.one-line.com/en/container-information) 与 [Maersk 设备资料](https://www.maersk.com.cn/~/media_sc9/maersk/local-information/files/africa/madagascar/overview/container-type-and-sizes/dry-equipment-specifications.pdf)。不能把示例净载货数字当作道路总重限值。

## 引擎与数据

- `src/data/vehicle-presets.json`：8 个模板。
- `src/core/multistop/vehicles.ts`：输入规格验证；`RouteProblem.vehicle` 保存车型、尺寸、载重及开放面。
- `doors.ts`：五种面与扫掠抽取柱；`x-min/x-max/y-min/y-max/z-max`。
- `access.ts`：人员地面走道与触及距离，侧卸按横向投影；吊装必须显式使用设备模式。缓存包含货物姿态，追加障碍后重新计算。
- `engine.ts`：每一步操作记录 `door`，临移/装入/放回在当时选择真实畅通方向；事务失败回滚。
- `planning.ts`：按选定方向分区；新车放不下全批起点时明确报错，不丢货换结果。
- `replay.ts`：复核实际方向是否开放、路径、可达、承托和库存。
- `playback.ts` / `RoutePlayer.tsx`：用操作记录沿 X、Y 或 Z 进出，保留其余坐标。
- `src/core/repair-packing.ts`：货舱尺寸改变后仍允许以独立合规的旧方案为修复起点；最终按新配置验证。
- `mac/assembly/Sources/main.swift`：常驻尺寸、3D 手柄、越界待装、撤销与取消计算。

## 当前边界

装配重算仍采用一批同规格货舱。多站点仍是单车、既定站序；不是车队车辆调度或路线寻优。

作业面按整面开启模拟，未显式建门洞框、侧柱、车轮拱、尾板、吊具尺寸或机器人轨迹。栏板/侧帘模式假设装卸前已开启对应面。设备模式不声明人员可达；人员模式只做地面方形站立区域与触及范围筛查。

仍需显式保存/导出，尚无通用项目自动保存。
