# 竞品能力逐项核对与实现台账

核对日期：2026-10-30。依据 [装箱大师产品功能表](https://www.zhuangxiang.com/product/) 的 41 项、[EasyCargo 优先组说明](https://www.easycargo3d.com/en/journal/do-you-need-to-load-or-unload-the-cargo-gradually-with-priority-groups-its-a-piece-of-cake/) 与 [EasyCargo 货物输入说明](https://help.easycargo3d.com/article/89/adding-items-to-the-load-plan-in-easycargo)，结合当前工作台及源码。竞品各版本的适用范围以其官方功能表为准；本表仅核对产品能力，不代表完成竞品全部版本。

状态定义：**部分**表示能完成某个子集，或引擎与 UI 未贯通；**未实现**表示没有可用的完整工作流。任何部分能力均不视为竞品等同。手工调查未覆盖竞品的全部边界和实测效果。

## EasyCargo 优先组：明确差距

- EasyCargo 的装载优先组编号小者先装入、先到车厢深处；我们当前 `unloadStop` 数字小者先卸，二者语义相反，不能直接互换。
- EasyCargo 公布尊重组分离、禁止跨组堆叠、虚拟墙隔离与忽略分离等选项；当前有可选“不同卸货站货物禁止直接叠放”硬约束，作用于非空腔内部的直接承托接触，并执行独立校验；**不代表竞品所有分组模式等价**。其他分组模式尚未实现。
- 当前阻挡仅是单方向外包投影及直接支撑的保守风险信号，不是倒货次数、装卸步骤或可达性证明，也不覆盖中途取货。
- 当前必须从 Excel 条目或模拟数据创建站序；缺少可命名／增删／调整顺序的站点列表和批量分配体验。
- 竞品具备货物新增、数量、颜色和方向等工作流；当前页面只能编辑已有批次部分参数，缺少完整新增、删除和约束编辑。

## 建议实施顺序与验收

1. **可用基础工作台**：Excel 列映射及逐行错误、增删货／数量、容器预设、单位和三轴间距、完整导入导出。验收：从模板导入一批货、修改货物和车厢、重算并导出可核对的逐件坐标和未装清单。
2. **多站优先组**：站点命名排序、批量分配、忽略／软偏好／严格分组；已有跨站直接叠放限制仍需扩展至完整分组体验。明确装载顺序和卸货顺序的方向。每种模式必须有违反约束时的独立反例测试，不能用简单阻挡数量替代硬约束。
3. **方案编辑与容器**：锁定货物／柜、修改后校验、有限数量和不同规格容器选型；验收包括锁定货物坐标不变、重算无遗漏、修改导致不可能时明确失败。
4. **专业装载**：门洞和操作通道、支撑与动态稳定、重心及轴荷、异形包装／托盘；逐步定义数据缺失时的待确认机制。
5. **交付与集成**：可审计装卸任务单、可交互静态分享和机器人任务数据、Excel/ERP/WMS；前提是任务顺序、设备能力和现场安全规则经过验证。

现阶段历史 11 柜方案依赖 PDF 几何投影承托假设；不得将其校验结果表述成实际 5 mm 空隙具备物理支撑，或声称全局最优。
