# CargoPlan Agent：多站点装卸规划

## 产品定位

面向零担、干线和工程物流的调度与仓储人员，把货物清单、站点和业务约束转成可检查的装载与逐站卸货方案，输出可视化作业清单及供机器人系统消费的任务草案。

## 黑客松演示

一个已知顺序的 A→B→C 三站场景：从清单导入 20–40 件异形/箱形货，按站点设定卸货需求。演示基准方案有遮挡；重新规划后展示每站取货步骤、阻挡及预计搬移次数。改变 B 站货量，展示重新规划和约束验证。导出方案 JSON 和货单。指标应基于同一数据、明确模型、可重放计算，不预设改善百分比。

先实现固定路线与单侧柜门的简化示例：在离散矩形障碍、沿柜门直线平移、无机械臂体积和货物旋转的假设下判定通道；显式显示受阻和无法计算。支撑关系、碰撞、方向、装载重量等已有校验必须继续生效；支撑或嵌套的货物须先安全移除，逐步重算余货稳定状态。不能证明可行时报告原因而不是虚构成功。若限时实现不完整，降级为展示障碍分析，不将其称为无倒货方案。

## Agent 工作流

导入与解释：读取结构化字段，提取自然语言限制并展示来源；不确定项交由用户确认。规划：将确认条件输入确定性求解器，按可行性、柜/车数、倒货次数、利用率等词典序比较。校验：独立验证完整性、几何、约束与逐站操作。解释和交付：以自然语言说明取舍，输出 3D 回放、作业清单、约束来源和结果版本。

## 机器人接口边界

任务草案包含方案版本、站点、货物ID、尺寸重量、当前位置与姿态、操作次序、目标、坐标系、单位、约束和状态。用于仿真及未来接口讨论；没有完成感知、抓取点、夹具匹配、轨迹规划、安全认证与现场联调，不能直接控制机器人。

## 差异与商业验证

EasyCargo 已有多站卸货优先组及3D手动调整，不能把多站点或3D图本身作为独有能力；其公开手动调整说明提示自由操作时需由用户遵守限制。可探索的差异为中文复杂约束与证据追踪、逐站遮挡解释和人工修改后的约束复核，以及适配企业/机器人系统的可审计任务数据。这些是待验证的产品假设，不代表竞品不存在相应能力。

首批访谈对象为工程物流、专线/零担承运商、仓库主管及系统集成商；确认倒货频率、人工规划时间、现场作业流程、既有软件、能否获得脱敏单据和购买预算。潜在收入包括按方案/席位订阅、企业API及实施服务，价格需要客户访谈验证。

## 三天优先级

1. 固定场景、数据、约束及可验证基线；实现目的站字段和单门通道检测。
2. 增加逐站卸货模拟与阻挡清单；在保持已有安全校验的前提下比较备选布局。
3. 接入 Agent 的规则解释、3D步进和作业单导出；完成回放测试、现场客户反馈和短演示。

备用方案：若优化器无法在时间内生成可靠改进，展示两个已验证可回放样例和可解释的阻挡检测，不把手工预设说成求解器实时生成。

## 现有项目资产及约束

项目已有 Excel 导入、3D 展示、货物方向/间隙/承重等模型和静态报告，可以作为技术经验；多站点任务及机器人接口需要新增。上海站官方要求竞赛代码和素材在活动期间产出，旧项目及案例数据能否用于参赛应向主办方确认，不能直接假定允许复用。现有伊拉克案例包含 W02 专项模型高度例外与实际柜体可装性未确认的问题，演示必须显式标注。实物承托、运输动态和作业路径也不能仅凭几何示意认定合规。
