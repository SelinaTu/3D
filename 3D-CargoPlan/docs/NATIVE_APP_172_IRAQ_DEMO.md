# CargoPlan 1.7.2 · 多站点继承 HTML 伊拉克完整数据

日期：2026-10-31。默认安装入口 `/Applications/CargoPlan.app`，build 9。

## 修正

上一版默认八件小样例，虽然能运行求解和动画，但没有体现完整伊拉克装配，这是演示体验退化。本版恢复默认「伊拉克完整基线 · 与 HTML 同源」。

- APP 与 HTML 工作台都经 `src/demo/iraq-baseline.ts` 读取同一个 `output/reports/iraq-villa-current-best.plan.json`。
- 校验完整 11 柜、1371 个唯一货物 ID、无未装件及已校验标记；读取失败显示错误和重试，不静默退回小样例。
- 提供 11 柜选择，保留选中柜的全部货物、原始参数、姿态和坐标；不是把整批 1371 件塞进一辆车。
- 默认第 1 柜 93 件；第 10 柜 238 件。八件示例保留为可选练习，当前装配货柜另有独立选项。
- 基线演示从只读副本出题，不覆盖用户的改参和待装；「当前装配货柜」继续要求先重算。
- 出题前将已选人员 / 设备方式传入初始容器，按相同可达规则构造任务，再交由通用引擎重新求解、重放和动画播放。

## 为什么柜号之前不一致

HTML 静态报告为了展示重新排序并编号为 `container-*`；原生首次启动场景沿用冻结计算结果的 `repair-v3-*` 顺序。两者逐件位置、实际占位、姿态和旋转相同，但数组下标及柜 ID 不相同。

因此本版的基线选择器与 HTML 使用同一顺序；回归通过货物身份比对物理布局，不能按不同版本的柜号直接推断内容。
