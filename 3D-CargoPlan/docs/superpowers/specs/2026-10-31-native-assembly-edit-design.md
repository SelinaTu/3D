# 原生装配编辑：待装池与重新计算

日期：2026-10-31。在 SceneKit 装配应用上接回网页装载规划工作台同一条编辑回路。

## 行为

1. 拖拽松手后若与其他货重叠，该件离开柜体，进入顶部待装池（暂存）。
2. 单击选中后可改尺寸、重量等参数；可退出编辑（取消选中），待装池保留。
3. 顶部始终有待装池摘要与「重新计算」。重新计算调用与网页相同的 `planWithComparison` / 贪心通路，输入为「仍在柜内 + 待装池」的完整货物清单及当前货舱参数；结果写回 3D，仍未装入的留在待装池。
4. 工作区标签：装配为本窗；多站点 / 知识 / 协议打开完整 CargoPlan 桌面应用对应能力。

## 不做

不把拖拽位置当作已校验的最终方案；不宣称真机执行。
