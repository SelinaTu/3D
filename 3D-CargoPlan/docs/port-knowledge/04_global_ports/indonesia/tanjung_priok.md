# Tanjung Priok (Jakarta) · IDTPP

> as_of: 2026-10-30 Asia/Shanghai · dossier depth: **medium**  
> National rules: `../../02b_indonesia_national.md`

## Role
Indonesia’s primary container gateway (~60% national logistics share often cited in Kemenhub ODOL communications). Operator cluster under **Pelindo Regional 2**; major terminals include **JICT**, **NPCT1**, others (**待核实** full list / concession changes).

## VGM / gate
- Terminal weighing + VGM required before load (JICT SOP published via carriers: gate weigh W1/W2 → VGM; **no VGM → cannot load**).  
  Source: [Emirates Line Indonesia weighing SOP PDF](https://www.emiratesline.com/wp-content/uploads/2024/03/0042-Indonesia-SOP-For-Operation.pdf).
- National: **PM 25/2022** (5% reweigh rule; CSC max ban).
- 2016 Port Authority + Syahbandar circular: export terminals must provide scales; significant weight difference → new VGM; **no dual-container combo on one chassis**.  
  Source: [Bisnis.com](https://ekonomi.bisnis.com/read/20160630/98/562824/tanjung-priok-terbitkan-4-pedoman-verifikasi-berat-kotor-peti-kemas).

## Road / ODOL leave-port
- Zero ODOL enforcement explicitly lists **ports** as focus points (Kemenhub/Korlantas 2025).  
- Historical **Tol akses Priok**: 5-axle total ~**45 t** (2017 PUPR/BPJT via media) — **待核实 if still posted limit**.  
  Source: [Liputan6](https://www.liputan6.com/bisnis/read/2921553/kontainer-melebihi-45-ton-tak-boleh-lalui-akses-tol-priok).
