# CargoPlan 1.7.1 · 自动出题演示恢复可用

日期：2026-10-31。默认入口仍是 `/Applications/CargoPlan.app`，版本 1.7.1 / build 8。

## 问题与原因

用户反映 APP 没有自动出题功能。实机检查发现原随机区存在，但当前装配有待装件、dirty=true，生成与换题均被禁用。此前只在交接文档写“保留”，没有解决实际不可用的问题。

## 当前入口与操作

1. 进入 APP「多站点」，顶部直接点击 **自动出题演示**。
2. 默认「独立演示车辆 · 8 件辅材」，可设置站点数、随机种子和示例类型。
3. 点击「生成题目」或「换一题」，查看生成的逐站装卸清单。
4. 点击「计算装卸方案」，再播放全程或按步骤查看拆卸、装入和临移。

独立演示采用 4.2 米示例厢车、参考伊拉克辅材尺寸量级的包装箱，默认五站、工人走道模式；不是客户原始库存。出题只生成数据，使用同一多站引擎求解和独立重放，不提供跳过校验的预制答案。随机挑战仍可能无解。

选择「当前装配货柜」仍要求装配先重算通过，不使用过期的旧摆放。用户真实待装与改参不会因演示被清除或重算；独立题目与导入计划不再被当前装配 dirty 状态阻止计算，切换标签或刷新原生装配上下文也不会清空独立题目。

## 实现

- `src/demo/MultiStopTest.tsx`：顶部入口、演示设置、独立 / 当前柜来源、题目来源状态及计算门控。
- `src/demo/route-demo.ts`：独立演示初始货舱和八件包装箱，没有用户装配依赖。
- `src/demo/route-demo.test.ts`：三个种子 × 起点重排开关，人员模式完整求解、库存 / 重放、动作数据、源数据不变及复现。
- `src/demo/route-workspace.css`：入口强调、出题参数与按钮布局。
- `mac/assembly/Sources/main.swift`：新增 `--route-demo-smoke`，回归“装配有 5 件待装，独立出题 / 求解 / 动画可用且原工作区不变”；更新已有壳测试流程。

验收记录、安装版日志和实机截图见 `output/native-171-validation/acceptance.json`。此前 1.7 的验收与截图继续保留在 `output/native-170-validation/`。

## 本次验收结果

36 文件 / 265 项测试、lint、类型检查和构建通过；13 项默认安装版原生检查通过。实机打开 1.7.1，在实际六件待装状态下生成五站题目，完成 16 件次卸货、8 件装货，五站全部任务完成并播放 / 暂停动画。更新和演示后，原生工作区 JSON 全量逐字段比较一致，未改动用户清单和待装状态。

从执行动画返回时，再点顶部「自动出题演示」会展开并滚动定位设置，保留已有题目与结果；此路径纳入安装版自检。
