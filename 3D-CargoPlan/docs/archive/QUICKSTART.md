# 快速使用指南

## 一分钟上手

### 1. 启动服务
```bash
./start.sh
```
或者
```bash
npm run server
```

### 2. 打开浏览器
访问：http://localhost:3000

### 3. 三步操作
1. 点击 "📦 加载示例数据"
2. 点击 "🎯 运行优化"
3. 查看最优方案

### 4. 停止服务
按 `Ctrl + C`

## 预期结果

- ✅ 7个集装箱（相比原方案节省4个）
- ✅ 77%体积利用率
- ✅ 约1-2分钟计算完成

## 常见问题

**Q: 页面打不开？**
A: 确认服务器已启动，查看终端是否显示 "Server running at http://localhost:3000"

**Q: 优化需要多久？**
A: 通常1-2分钟，1196个货物单元，4种算法并行计算

**Q: 如何使用自己的数据？**
A: 修改 `src/server/api.ts` 中的文件路径，格式参考示例Excel

**Q: 服务器占用端口？**
A: 默认3000端口，可在 `src/server/index.ts` 修改

## 技术支持

遇到问题？检查：
1. Node.js版本 >= 18
2. 依赖已安装（npm install）
3. 示例Excel文件路径正确
4. 端口3000未被占用
