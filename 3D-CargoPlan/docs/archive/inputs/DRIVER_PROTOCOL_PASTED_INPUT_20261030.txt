调研下这些平台的痛点【✅ 大车顺路/返程外快平台（按最适合你的排序，6.8/9.6/13米高栏、厢车都能用）
 
1. 运满满（满帮）【首选】
长途干线最多，自带顺路订阅、返程匹配，支持设置出发→终点方向，沿途、回头货都多；满运宝担保，适合你主线跑完，顺路捎货、回程不空跑，缺点低价黄牛单多，要自己筛。
 
和货车帮是一家，两个司机端都可以装上。
 
2. 省省回头车
定位就是回头车、顺路货，专门做返程配货，很多货主就是找返空大车，对顺路司机友好，华南、华东线路货源很强，适合跨省回来找单。
3. 物通网（车主版）
工厂一手货源偏多，整车、零担拼货都有，可以提前订阅线路顺路货源，适合找沿途拼单分摊油费，会员可以过滤中介单。
4. 沙师弟货车导航
导航+顺路配货一体，跑长途路上直接看同方向货源，适合边走边捡顺路小单。
5. 鱼泡网
不光工地，物流专线、物流园的零散整车顺路活很多，不少专线老板直接发单，适合找长期固定线路的顺路货源。
6. 货拉拉司机版、滴滴货运
偏同城、短途跨城，长途干线顺路单少，如果你主线沿途经过大城市，可以顺带接短途小货，不适合跨省长途回程主力。
 
 
 
⚠️ 跑顺路外快重点提醒（非常重要）
 
1. 合规第一：不能超载，看清货物品类，危险品、违禁货坚决不接；你的营运证、保险要确认，顺带货也属于营运。
2. 接单前算成本：高速费、时间、装卸等待，不要为了不空跑接亏本低价单。
3. 优先走平台担保交易（满运宝等），少私下微信转账，防止运费拖欠。
4. 技巧：还没卸货，提前在平台订阅返程/顺路方向，比卸完货再找单更容易抢到好货。

0. 一句话结论
痛点结论： 六类 App 的红海都在 车货撮合 / 导航找货；司机侧高频伤是 低价·倒货·黄牛、超载订单与拒单扣分、运费拖欠与线下失联、装卸等待算不清账、返程空驶、信息碎片化——公开报道与平台自救公约高度重合。用户排序把运满满/满帮放首选、货拉拉/滴滴货运放同城补充，方向大体成立；但「省省」已并入满帮系叙事，鱼泡网本质是 招工找活 而非干线配货主平台，需降权。

我们的楔子： 不做第二个满帮。做 接单前的装载·合规·政策证据层——导入货单尺寸重量 → 3D 装配预演 → 轴荷/超载/品类风险提示 → 港口·口岸·园区政策速查（Port Pack） → 导出装载图/证据包给货主或安检 → 可选多卸点顺序。与撮合 App 并行，帮司机回答：「这单顺路值不值得接、装不装得下、会不会超、到港/园区会不会踩政策雷。」

与满帮等关系（写进产品原则）：

MVP = 并行工具 / 浏览器或小程序，司机继续在运满满/货车帮/沙师弟找货。
不宣称「我们货源更多」。
远期可谈：Open API / 小程序插件 / 分享链接嵌入（需对方商务，待核实）。
网络效应承认：撮合是红海且满帮极强；我们卖的是 装载与合规证据。

3.5 MVP / Phase 2 / 路演叙事
阶段	范围	成功标准
MVP（ClawHunt 可演示）	3 种车型 profile（6.8/9.6/13）；手工货单 → 3D 能否装下；超载/超方提示；演示港 3–5 政策 checklist；导出分享图；多卸点 1 个坏→好对比	评委/司机 90 秒看懂「接这单前先预演」
Phase 2	车队长多车；OCR/粘贴导入；利润粗算模板；P0 Port Pack 填表；品类危禁库；等待/倒货工时；与 1 家车队试点	≥1 付费或深度试用车队；节省可口述
后期（可选）	撮合平台插件商务；园区/货主只读链接；机器人任务草案（规划层，见双臂附录）——仍非控机	集成意向，非装机量吹牛
ClawHunt 路演 30 秒加一句：
「满帮解决有没有货；舱策解决这货装不装得下、超不超、到港会不会踩政策——3D 可验证，给司机和货主同一份证据。」

3.6 商业化草图（司机侧）
模式	说明
司机 freemium	基础「装得下吗」免费；多卸点/Port Pack/导出水印去除订阅
车队席位	车型库 + 证据归档 + 规则包加购
货主/货代侧反哺	同一引擎服务货代主方案；司机端获客
价格不预设；门槛同主方案：可回放样本、与竞品差异可重复、节省 > 成本。

4. 合规与产品红线
不鼓励超载：超载风险提示是为了 拒单/改车型，禁止「如何瞒过称重」任何指引。
危禁品：仅提示「可能需资质/禁运」，不提供伪装运输建议。
营运与保险：文案提醒捎货仍属营运；产品 不代办证件。
非法律意见 / 非罚单计算器：罚款区间引用公开规定并标来源；UI 固定免责声明（对齐主方案 §7.5）。
不编造港别独家装柜法：Port Pack 只挂可溯源 stub + checklist（见 CLAWHUNT_PORTS_P0_P1.md）。
不替代担保：引导走满运宝等平台担保；我们不做资金存管。
不夸大：不宣称独家多站/独家 3D；不宣称取代满帮网络效应。
隐私：货单与车牌等默认本地/加密；不做金融放贷。
机器人：司机产品与柜内机器人解耦；任务草案仅后期可选脚注。

 省省/运满满当前司机端「华南华东回头货」相对强度（用户排序 vs 实际线路）——需司机访谈。
 物通网会员「过滤中介单」是否仍为明确卖点及效果。
 沙师弟担保交易覆盖车型/线路与纠纷垫付规则细表。
 鱼泡上「物流专线发货」vs「招司机」占比（产品是否值得做导入）。
 6.8/9.6/13 高栏·厢 内廓尺寸与额定 车队常用表（建 profile 库）。
 司机愿为「接单前 3D」付费的价格敏感度；车队长是否比个体更早付费。
 与满帮/沙师弟官方插件或分享卡片合作可行性。
 司机侧「装不下导致拒收/二次倒货」发生频率（缺公开统计）。
