# AI装箱优化系统 🎯

> 运筹学算法 × 沙盘自进化 × 实时进度可视化

## ✨ 核心特性

- **7种优化算法**：贪心、遗传、分支定界、禁忌搜索、蚁群、混合
- **实时进度显示**：SSE推送，1-2分钟计算过程全可见
- **沙盘自进化**：从历史决策中学习，逐步逼近最优策略
- **约束规划框架**：灵活添加业务规则（硬约束+软约束）
- **智能算法选择**：根据问题规模自动选择最优算法组合

## 🚀 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动服务（注意：编译可能有类型错误，但服务器可运行）
npm run server

# 3. 打开浏览器
open http://localhost:3000
```

## 📖 使用指南

### 1. 加载数据
点击 **"📦 加载示例数据"**，系统会加载伊拉克项目的1196个货物单元。

### 2. 运行优化
点击 **"🎯 运行优化"**，系统将：
- 显示实时进度条
- 依次运行多种算法
- 1-2分钟后返回结果

### 3. 查看结果
- 多个方案按评分排序
- 🏆 标记最优方案
- 显示详细指标：
  - 集装箱数量
  - 体积利用率
  - 重量利用率
  - 执行时间

### 4. 学习报告
点击 **"📊 查看学习报告"**，查看沙盘学习系统的权重和决策统计。

## 🧠 沙盘自进化

系统会记录每次装箱的**决策路径**，学习：

1. **成功模式**：高利用率的决策特征
2. **失败模式**：低利用率的决策特征
3. **权重调整**：自动优化启发式规则

学习权重包括：
- 体积优先（大件先放）
- 靠角放置（边角利用）
- 分层构建（水平分层）
- 重量平衡（重心居中）
- 旋转偏好（方向选择）

## 🔧 配置

### 容器参数

默认使用标准40尺高柜：
```typescript
{
  length: 12032 mm
  width: 2352 mm
  height: 2393 mm
  maxWeight: 27000 kg
}
```

### 算法参数

可在 `src/core/optimizer.ts` 中调整：
- 遗传算法种群大小：30
- 遗传算法代数：50
- 禁忌搜索迭代次数：100
- 蚁群蚂蚁数量：20
