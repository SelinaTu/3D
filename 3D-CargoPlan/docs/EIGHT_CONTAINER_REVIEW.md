# 8柜方案审核 · 2026-10-18

**结论：货量真实齐全，这是一份更宽松条件下的8柜几何方案，不能作为已确认PDF规则下通过验收的8柜解。** 独立扫描确认它在自身大箱体、零间距条件下没有货物实体穿插；问题集中在净空、间距、孔内使用、顶部限重和叠放层数。不能据此断言同题8柜无解，也没有据此证明现有11柜全局最优。

## 货物没有少装或缩小

逐源表、源行、单位序号映射90条原始源行、1371个独立ID：门窗1196、玻璃架30、辅材145；总重134777.37kg，外包盒总量590.112711447m³。所有单件原轴尺寸、数量和重量与已校准清单一致。附件plan、CSV、HTML静态数据的1371件坐标和姿态相符；`position_u`为0.5mm单位，不存在把单位误读成毫米的问题。

原Excel字节SHA与附件所声明Excel SHA不同，ZIP没有附其来源工作簿，因此目前证明的是物理库存等价，不能据此声称所有原始规则单元格同版。

## 为什么能做到8柜

| 项目 | 已确认验收规则 | 附件8柜实际情况 |
|---|---|---|
| 箱体净空 | 11600×2250×2500mm；指定W02高2560例外 | 12000×2340×2680mm，单柜75.2544m³，比原65.25m³多 **15.33%** |
| 留缝 | 玻璃架彼此0mm，其余XYZ均5mm | 发现 **5339对不足5mm**，其中5313对为0mm接触 |
| W02孔内门窗 | 原宽轴竖直，禁止额外窗面90°旋转 | **92件W04**原长轴竖直进入孔内 |
| W01长框孔内门窗 | 必须侧放，原宽轴竖直 | **253件门窗平放**进入孔内 |
| W01短框空腔 | 只允许辅材 | 放入 **46件W01扇** |
| W07/W11/W12顶部单件 | 上件≤5kg | 129对直接接触关系超过限制，涉及40个不同上件；包括81kg W11叠W11、74kg W12叠W12 |
| 长框/W06扇平放件数 | 每柱总数≤10 | 4柱长框各12件；W06扇两柱分别15、13件 |
| 支承物 | 未按PDF另加实物隔垫；采用已声明投影载荷模型 | 新增305木架、2604木件，净体积4.12784m³；质量全空，材料等级、连接及强度未验 |

各项共同扩大了几何求解自由度，不能将减柜数量全部归因于某一个因素，或据此量化某条放宽单独节省了几柜。

三种居中孔的归一尺寸和偏移与当前合同相同，没有发现孔尺寸被造大。差异在于如何使用这些孔：附件599件孔内货物中，**391件违反已确认的方向或对象限制**（92+253+46）。

## 直接可复核的反例

1. **箱体越界**：`cargo.csv:43`，柜001 `AC-R24-001`，位置(11304,0,2430)，尺寸350×390×250mm，终点X=11654、Z=2680，分别超原净空54和180mm。换回原净空及W02专项例外，全方案共289件越界；X77/Y93/Z143为可重叠的按轴计数，不能相加作件数。
2. **零间距**：柜001 `AC-R05-001`的Y=1200、宽460，其邻件`AC-R05-002`的Y=1660，间隔0；均非玻璃架0mm特例。长框`MC-R23-041`从Z=0高210，其上`MC-R23-001`从Z=210开始，竖直间距也为0。
3. **孔内旋转**：柜001 `MC-R06-024`（原W04）在`MC-R16-024`的W02孔里，实际1030×120×1330mm，原长1330竖直；已确认应原宽1030竖直。它能几何塞入1200长孔，恰恰依赖已明确不允许的这次窗面旋转。
4. **孔内越权类别**：柜001 `MC-R22-022`（100kg W01扇）平放于`MC-R21-022`短框孔，该孔原表只允许辅材。
5. **顶部5kg**：柜003 `MC-R14-023`（W11）Z=1645、高150，其上同XY的`MC-R14-024`从Z=1795开始，直接叠放上件81kg，超过5kg。柜008 `MC-R15-012`/`MC-R15-013`同样直接叠放74kg W12。
6. **件数上限**：柜002、003各有两柱长框从Z=0按210mm节距连续堆12件。柜008 W06扇在XY=(6550,220)从Z=220至1760连续15件平放；另一柱XY=(9204.5,220)为13件。它们都超过源表10件上限。

仅扩大箱体或补上5mm不能消除81kg>5kg、12/15件>10件或孔内类别冲突，必须重新配货和布局。
