# 校准与压尾柜进展

本轮按用户要求串行执行：先校准题目，再优化。用户已授权这两个阶段，不需要重新批准开始第二阶段。

## 本轮结果

数据校准已经完成；优化真实尝试已完成一轮，当前最好为 **12 柜、1371 件全部装入、0 件未装，独立几何与载荷假设校验通过**。该结果尚未胜过原人工 11 柜；没有得到完整 11 柜压尾柜方案或 10 柜方案，不声称最优。

程序在同一新口径下从完整14柜推进到13柜，再通过局部重排达到12柜。排序研究、同源堆列、短玻璃架90度串列、拆柜重插均有真实日志。部分少柜候选仍留有未装货物，未纳入成果。原PDF仍缺精确坐标，不能把它直接当作已通过当前逐件校验的程序种子。

新版离线报告为 `output/reports/iraq-villa-calibrated-research.html`，包含12柜交互3D、真实框梁/空腔、1371件逐件清单、包络与实体双体积以及原11柜对照。报告明确标注研究结果和几何假设范围。当前最好坐标方案为 `data/calibration/current-best-research.json`。

- **货物对账已通过。** 原 PDF 的 191 行分柜明细、Excel 的 90 个源行与当前 1371 个单件，物理货物多重集合差异为 0；源字段差异、重复和漏件均为 0。门窗 1196 件、玻璃架 30 架、辅材 145 箱，总重 134777.37 kg。
- **尺寸与业务语义已校准。** 使用 11600×2250×2500 mm 净空，只有指定源行的 W02 框可高至 2560 mm；三组居中孔、孔内来源/方向限制及上件最大面积面朝下按用户确认执行。非架对架三轴 5 mm，玻璃架对架 0 mm。
- **已修正空腔端面。** 贯通孔的开放端面不再被当作实体墙内缩；子件仍须完整位于授权孔包络内，并与真实框梁保留 5 mm。几何校准没有放松真实材料间隙。
- **竖向规则已按用户回复固定。** 用户答复“参考PDF如果没有就不用”。PDF未注明隔垫，因此采用 `verticalSupport: 'pdf-clearance-projection'`：5 mm为几何预留，按上下投影核算叠放载荷，不增加实物垫料，也不把该计算称为实际接触承托证明。
- **校准完成，进入第二阶段。** 合同 `status=ready`，已获准的两阶段任务自动继续。候选按 `geometry-and-load-assumptions` 范围校验；尚未得到新口径完整11柜方案时必须明确记录。

## 严格接触模型与本题的区别

在没有隔垫或其它已定义支撑的条件下，任何非玻璃架货物与下件接触都会违反 5 mm 间隙；有空气间隔则不能传力，所以这些货物只能落地。

逐件枚举合法朝向、扣除真实孔材后的最小地板接触面积，1341 件非玻璃架合计 **469.96215 m²**。单柜地板 **26.1 m²**，11 柜共 **287.1 m²**。即使完全忽略玻璃架地板占用和水平缝，仍需至少 `ceil(469.96215 / 26.1) = 19` 柜。

这只是“所有方向 5 mm + 无隔垫传载 + 必须真实接触”的另一严格模型下界，**不适用于本轮按PDF采用的几何投影模型，不是对原人工11柜的否定，也不是完成了装箱优化**。保留它是为了说明模型边界，不能据此停止本题搜索。

## 第二阶段的验收目标

候选首先必须全部 1371 件入柜、原始数据不变、独立校验有效，然后依次比较：

1. 柜数更少；10 柜优于 11 柜。
2. 同柜数时，按扣除已确认空腔的体积排序，尽量压低尾柜体积。
3. 同等尾柜体积下，提高前 10 柜中最低的实体体积占用率，同时列出前 10 柜平均值。

报告同时列出外包络体积和扣除空腔后的简化实体体积。后者仍是矩形框梁模型，并非铝材真实材料体积测量；不得混用两种口径制造改善。

原 PDF 第 11 柜有 **93 件、41.549138447 m³**，未含本次确认的三类空腔。按实体体积排序，原方案最低的是第 1 柜 **39.312162536 m³**，其外包络为 49.688562536 m³。两项基准都会保留；仅换柜号或排序不算压尾柜成功。

## 可重复运行

```sh
npm run calibrate:data
npm run research:prepare
npm run check
```

第一条重新读取项目内原 PDF 副本、Excel 和标准化清单，输出对账与条件下界。第二条检查合同和来源哈希，默认不运行优化；实际研究使用脚本的显式运行参数。第三条运行代码检查、测试与生产构建。

已按用户回复更新版本化合同，固定配置和来源哈希，继续完整同口径基线与压尾柜搜索。研究应保留候选日志、首次完整基线和当前最好方案；找不到 10 柜时，交付真实有效的当前方案和量化差距，不声称全局最优。
