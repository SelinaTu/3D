# 先从这里开始

1. 打开 START_HERE.md，查看代码地址、方案进展、源码与已安装 APP 的差异。
2. 打开 CURSOR_HANDOVER.md，了解架构与关键约束。
3. 本包是实际工作区源码快照，包含尚未提交 Git 的文件；不是旧仓库克隆。
4. npm ci 后 npm run check；先构建网页，再 zsh mac/assembly/build.sh。
5. output/reports/iraq-villa-current-best.plan.json 为 Web 和 APP 共用的必要完整基线，已随包包含。
6. package-validation/ 是本包独立安装 / 测试 / 构建记录；output/native-172-validation/ 是已安装 1.7.2 的历史验收。
7. Mac 体验包另行提供，当前版本 1.7.2，arm64 / macOS 26 本机测试；个人自动保存不在包内。
8. 本包不包含约 1 GB 历史搜索中间结果或可选的工程外原文知识库。
